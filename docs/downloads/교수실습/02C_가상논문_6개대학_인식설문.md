# [가상 논문 C] 대학생의 생성형 AI 학습 활용 실태와 인식: 6개 대학 설문

> **교육용 가상 자료입니다.** 저자, 학술지, 대학, 수치는 모두 만든 것입니다. 실제 연구로 인용하지 마세요.

- 저자: 가상저자 김도영, 가상저자 최은설, 가상저자 문태호 (가상 고등교육정책연구소)
- 학술지: 「가상 고등교육정책」 제12권 1호, 2026, 7–29쪽
- 가상 문헌 번호: VHEP-2026-0107

## 초록

6개 대학 학생 1,204명에게 생성형 AI를 공부에 어떻게 쓰는지 물었다. 생성형 AI가 학습에 도움이 된다는 응답은 78.3%였다. 과제 초안 작성과 개념 설명 요청이 가장 흔한 용도였다. 스스로 생각하는 시간이 줄었다는 응답도 적지 않았다.

## 1. 연구 방법

- 설계: 횡단 설문조사. 학습 성취는 측정하지 않았다.
- 참여자: 6개 대학(수도권 2, 비수도권 4) 재학생 1,204명.
- 시기: 2025년 5월, 온라인 설문 1회.
- 표집: 대학별 온라인 공지로 자발적 참여를 받았다.

## 2. 결과

### 2.1 사용 경험

- 응답자 1,204명 중 한 학기 동안 공부에 생성형 AI를 써 본 학생은 862명(71.6%)이었다.
- 나머지 342명(28.4%)은 쓰지 않았다.

### 2.2 사용 경험이 있는 학생 862명의 응답

| 문항 | 그렇다 비율 | 인원 |
|---|---|---|
| 학습에 도움이 된다 | 78.3% | 675명 |
| 과제 초안을 쓸 때 쓴다 | 64.0% | 552명 |
| 개념 설명을 요청한다 | 59.4% | 512명 |
| 스스로 생각하는 시간이 줄었다 | 41.2% | 355명 |
| 수업의 AI 사용 규칙을 모른다 | 52.7% | 454명 |

- 2.2의 비율은 모두 **사용 경험이 있는 862명**을 기준으로 계산했다.
- 전체 응답자 1,204명을 기준으로 하면 '학습에 도움이 된다'는 675명, 56.1%다.

## 3. 한계

- 자발적 참여라 AI에 관심 많은 학생이 더 많이 응답했을 수 있다.
- 학생 인식만 물었다. 실제 성적이나 학습 향상은 확인하지 않았다.

## 4. 결론

학생 다수는 AI가 도움이 된다고 느꼈다. 그러나 절반 이상이 수업의 AI 사용 규칙을 몰랐다. 교수는 수업마다 AI 사용 규칙을 분명히 알려야 한다.
