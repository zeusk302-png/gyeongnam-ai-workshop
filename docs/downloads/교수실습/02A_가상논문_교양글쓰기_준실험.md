# [가상 논문 A] 교양 글쓰기 수업에서 생성형 AI 피드백이 글쓰기 점수와 작성 시간에 미친 영향

> **교육용 가상 자료입니다.** 저자, 학술지, 대학, 수치는 모두 만든 것입니다. 실제 연구로 인용하지 마세요.

- 저자: 가상저자 서민호, 가상저자 유하린 (가상 누리대학교 교양교육원)
- 학술지: 「가상교육공학연구」 제41권 3호, 2025, 45–62쪽
- 가상 문헌 번호: VEDU-2025-0341

## 초록

이 연구는 교양 글쓰기 수업에서 생성형 AI 피드백을 쓴 학생과 쓰지 않은 학생의 글쓰기 점수를 비교했다. 한 대학의 8개 분반, 212명이 참여했다. 실험 집단은 초고를 AI에게 보여 주고 피드백을 받은 뒤 고쳐 썼다. 8주 뒤 실험 집단의 글쓰기 점수가 더 높았다(d = 0.42). 과제 작성 시간은 평균 23% 줄었다.

## 1. 연구 방법

- 설계: 준실험. 분반 단위로 집단을 나눴다. 학생을 무작위로 배정하지 않았다.
- 참여자: 1학년 212명. 실험 집단 4개 분반 108명, 비교 집단 4개 분반 104명.
- 기간: 2024년 2학기 중 8주.
- 처치: 실험 집단은 매주 초고를 AI에게 보여 주고 구조·근거·문장에 대한 피드백을 받았다. 비교 집단은 같은 과제를 동료 피드백만으로 고쳤다.
- 측정: 사전·사후 글쓰기 평가(100점). 평가자 2명이 집단을 모른 채 채점했다(평가자 간 일치도 0.86). 과제 작성 시간은 학생이 직접 기록했다.

## 2. 결과

| 구분 | 실험 집단(108명) | 비교 집단(104명) | 차이 |
|---|---|---|---|
| 사전 점수 평균 | 65.3 | 63.2 | 2.1 |
| 사후 점수 평균 | 72.4 | 68.1 | 4.3 |
| 사전 점수를 통제한 사후 차이 | | | 2.6 |
| 과제 1편 평균 작성 시간 | 72분 | 94분 | −22분(−23%) |

- 사전 점수를 통제한 공분산분석에서 차이는 2.6점이었다(p = .004, d = 0.42).
- 사후 점수만 단순 비교하면 4.3점 차이다. 그러나 두 집단은 처음부터 2.1점 차이가 있었다.
- 하위 영역에서는 '구조'가 가장 많이 올랐고, '독창성'은 차이가 없었다(p = .47).

## 3. 한계

- 무작위 배정이 아니어서 분반 차이가 결과에 섞였을 수 있다.
- 작성 시간은 학생 자기 기록이다.
- AI 없이 혼자 쓰는 능력은 따로 측정하지 않았다.

## 4. 결론

AI 피드백은 글의 구조를 다듬는 데 도움이 되었다. 다만 효과는 사후 점수 차이(4.3점)보다 작은 2.6점으로 보는 것이 맞다. 혼자 쓰는 능력이 늘었는지는 후속 연구가 필요하다.
