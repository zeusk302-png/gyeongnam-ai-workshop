# [가상 논문 D] 가이드가 있는 AI 사용, 자유로운 AI 사용, AI 금지: 통계학 입문 수업의 3집단 비교

> **교육용 가상 자료입니다.** 저자, 학술지, 대학, 수치는 모두 만든 것입니다. 실제 연구로 인용하지 마세요.

- 저자: 가상저자 오세진 (가상 바다대학교 통계학과)
- 학술지: 「가상 통계교육 연구」 제9권 4호, 2025, 211–230쪽
- 가상 문헌 번호: VSER-2025-0211

## 초록

통계학 입문 3개 분반을 가이드 사용, 자유 사용, 사용 금지 조건에 하나씩 배정했다. 15주 뒤 AI 없이 치른 기말 시험에서 가이드 사용 분반은 금지 분반보다 6.8점 높았다. 자유 사용 분반은 금지 분반보다 2.1점 낮았지만 통계적으로 의미 있는 차이는 아니었다.

## 1. 연구 방법

- 설계: 분반 단위 무작위 배정. 3개 분반을 추첨으로 세 조건에 하나씩 배정했다.
- 참여자: 한 대학 통계학 입문 수강생 156명. 조건별 52명.
- 기간: 2025년 1학기 15주. 같은 교수가 세 분반을 모두 가르쳤다.
- 조건
  - 가이드 사용: 교수가 만든 질문 예시를 쓰고, AI 답을 확인한 과정을 과제에 함께 냈다.
  - 자유 사용: 제한 없이 AI를 쓸 수 있었다.
  - 사용 금지: 과제에 AI를 쓰지 않기로 약속했다.
- 측정: AI 없이 치른 기말 시험(100점).

## 2. 결과

| 조건 | 인원 | 기말 시험 평균 | 금지 분반과 차이 | p |
|---|---|---|---|---|
| 가이드 사용 | 52 | 74.9 | +6.8 | .01 |
| 자유 사용 | 52 | 66.0 | −2.1 | .38 |
| 사용 금지 | 52 | 68.1 | 기준 | |

- 가이드 사용 분반 학생의 83%가 'AI 답이 틀린 것을 찾아낸 적이 있다'고 답했다.
- 자유 사용 분반에서는 같은 응답이 38%였다.

## 3. 한계

- 분반이 3개뿐이다. 분반 자체의 차이와 조건의 효과를 나누기 어렵다.
- 한 대학, 한 교수의 수업이다.
- 사용 금지 분반이 실제로 AI를 안 썼는지는 확인할 수 없다.

## 4. 결론

AI를 쓰게 하느냐보다 어떻게 쓰게 하느냐가 중요했다. 확인 과정을 과제에 넣은 수업에서 혼자 푸는 점수가 올랐다.
