## 4. 강의계획서 초안 (`05_강의계획서_초안.md`)

### 4-1. 찾아야 할 문제 (핵심 6개 + 추가 6개)

| 위치 | 문제 | 고치는 방향 |
|---|---|---|
| 평가 방법 | **비율 합이 110%** (10+15+15+25+35+10) | 100%로 조정. 어느 항목을 줄일지는 교수가 결정 → [확인 필요] |
| 평가 방법 | **'결석 5회 이상 F'** | 학칙 제12조: 결석 8회부터 F, 지각 3회=결석 1회 |
| 평가 방법 vs 주차별 일정 | **과제2 마감 10/20 vs 10/15** | 하나로 정하고 전체 공지(M13과 연결) |
| 주차별 일정 | **9주차가 두 번, 13주차 없음** | 번호를 10~16으로 다시 매김 |
| 평가 방법 | 늦은 제출 감점 기준 없음("늦게 내면 감점") | 예: 24시간 이내 몇 % 감점 → [확인 필요] |
| 기말 프로젝트 | 평가 기준 "추후 안내", 조 점수 동일 | 루브릭 공개, 개인 기여 반영 |
| 기본 정보 | 면담 장소 "추후 공지", 시간 모호 | 요일·시간·장소 명시 |
| 기본 정보 | 공지 채널이 LMS와 단체 대화방 두 곳 | 공식 공지는 LMS 한 곳 |
| 수업 목표 | 명사 나열, 확인할 수 없는 목표 | "~할 수 있다" 문장으로 |
| 기타 | "결석 시 사유서 제출" | 학칙 제13조: 포털 '공결 신청', 7일 안 |
| 기타 | 슬라이드 수업 후 업로드 | 수업 전 게시(강의평가 T09, M10) |
| 기타 | AI 사용 원칙 없음 | 5번 활동에서 문구 작성(M18, 논문 C의 '규칙 모름' 52.7%) |

참고: 4주차 "9/24 휴강 확인"은 추석 연휴와 겹치는 날입니다. AI가 휴강 여부를 지어내지 않는지 봅니다.

### 4-2. 루브릭 확인 기준

- 기준 5개, 수준 4단계, 배점 합 100점.
- '개인 기여' 기준과 조원 평가 반영 방법이 있음.
- 칸마다 관찰할 수 있는 행동("공공데이터 출처와 연도를 표에 밝혔다")으로 씀.
- 계획서에 없는 제출물(예: 영상)을 더하지 않음.

## 5. 학생의 AI 사용 (150–170분)

### 5-1. 과제 재설계에서 볼 것

- 학생이 직접 만든 자료가 있는가: 지역 현장 사진, 짧은 인터뷰, 직접 모은 설문.
- 과정이 남는가: 분석 로그, AI 대화 일부 첨부, 중간 점검 기록.
- 말로 확인하는가: 발표 뒤 질의응답, 조원별 1분 설명.
- AI 탐지 프로그램에 기대지 않는가.

### 5-2. AI 정책 문구에서 볼 것

- 허용·조건부 허용·금지가 표로 나뉘었는가.
- 표시 문장 예: "이 보고서의 문장 다듬기에 ○○ AI를 사용했고, 분석과 결론은 직접 작성했습니다."
- 위반 시 처리는 [학칙 확인]으로 남겼는가. 가상 학칙 발췌에는 AI 관련 조항이 없습니다.
- M18 송지안의 질문("맞춤법만 고쳐도 되나, 어떻게 표시하나")에 이 문구로 답할 수 있는가.
- 근거 연결: 논문 D(확인 과정을 넣은 가이드 사용이 효과), 논문 C(사용자 52.7%가 규칙을 모름).
