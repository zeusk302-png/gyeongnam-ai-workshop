# 가온대학교 학사운영 규정 발췌 — 출석·과제·성적

> **교육용 가상 자료입니다.** 가온대학교는 실습을 위해 만든 가상 대학입니다. 실제 경남대학교나 다른 대학의 학칙이 아닙니다. 실제 업무에는 소속 대학의 학칙 원문을 쓰세요.

- 적용 학기: 2026학년도 2학기
- 발췌 범위: 제12조~제19조, 별표 1
- 이 발췌에 없는 일(추천서, 면담, 장학금 등)은 여기서 판단하지 않습니다.

## 별표 1. 2026학년도 2학기 주요 학사 일정

| 일정 | 기간 |
|---|---|
| 개강 | 2026-09-01(화) |
| 수강정정 | 2026-09-01(화) 09:00 ~ 2026-09-07(월) 17:00 |
| 수강철회 | 2026-10-13(화) 09:00 ~ 2026-10-16(금) 17:00 |
| 중간고사 주간 | 2026-10-20(화) ~ 2026-10-23(금) |
| 기말고사 주간 | 2026-12-15(화) ~ 2026-12-18(금) |
| 성적 입력 마감 | 2026-12-21(월) 17:00 |
| 성적 공개 | 2026-12-22(화) 09:00 |
| 성적 이의신청 | 2026-12-22(화) 09:00 ~ 2026-12-24(목) 18:00 |

참고: 2026학년도 1학기 성적 이의신청 기간은 2026-06-24(수) 09:00 ~ 2026-06-26(금) 18:00이었습니다.

## 제12조(출석)

1. 결석한 시간이 그 과목 전체 수업 시간의 4분의 1을 넘으면 성적은 F입니다.
2. 주 2회, 15주 수업인 과목은 전체 30회로 봅니다. 결석이 8회가 되면 F입니다. 결석 7회까지는 F가 아닙니다.
3. 지각 3회는 결석 1회로 봅니다. 조퇴도 지각과 같이 셉니다.
4. 공결로 인정된 날은 결석 횟수에 넣지 않습니다.

## 제13조(공결)

1. 다음 사유는 공결로 인정합니다.

| 사유 | 인정 기간 | 증빙 서류 |
|---|---|---|
| 예비군·민방위 훈련 | 훈련일 | 훈련 통지서 또는 훈련 필증 |
| 본인 결혼 | 5일 | 청첩장 |
| 부모·배우자 사망 | 5일 | 가족관계증명서와 부고 또는 사망 사실 확인 서류 |
| 조부모 사망 | 3일 | 가족관계증명서와 부고 또는 사망 사실 확인 서류 |
| 입원 | 입원한 날부터 퇴원한 날까지 | 입원확인서 |
| 법정 감염병 격리 | 격리 기간 | 격리 통지서 또는 진단서 |
| 학교 대표로 대회·행사 참가 | 행사 기간 | 학과장 확인 공문 |

2. 외래 진료, 감기 같은 일반 질병은 공결 사유가 아닙니다. 결석으로 처리합니다. 담당 교수는 결석 사유를 기록해 둘 수 있습니다.
3. 학생은 사유가 끝난 다음 날부터 7일 안에 학생 포털 '공결 신청'에 서류를 올립니다. 이메일로 받은 서류는 공결 신청으로 보지 않습니다.
4. 예비군 훈련, 대회 참가처럼 미리 알 수 있는 사유는 미리 신청합니다.
5. 7일이 지나면 공결로 인정하지 않는 것이 원칙입니다. 다만 입원 등 부득이한 사정으로 늦었다면 학과장 확인을 거쳐 처리할 수 있습니다. 담당 교수 혼자 결정하지 않습니다.
6. 공결 기간에 시험이나 과제가 있으면 담당 교수가 다음 중 하나로 처리합니다: 대체 시험, 제출 기한 연장, 다른 평가 점수로 환산.

## 제14조(과제 제출)

1. 과제 마감일과 늦은 제출의 감점 기준은 강의계획서를 따릅니다.
2. 과제 기간과 공결 기간이 겹치면 겹친 날수만큼 마감을 늦춥니다.
3. 성적 입력 마감(2026-12-21 17:00) 뒤에 낸 과제는 성적에 넣을 수 없습니다.

## 제15조(성적 평가)

1. 상대평가 과목은 A(A+, A0)를 수강생의 35% 이내로, A와 B를 합쳐 70% 이내로 줍니다.
2. 강의계획서에 없는 추가 과제나 개인별 점수 조정으로 성적을 바꿀 수 없습니다.
3. 시험을 보지 않은 학생의 점수는 0점입니다. 공결이면 제13조 6항을 따릅니다.

## 제16조(성적 이의신청과 정정)

1. 학생은 성적 공개 후 이의신청 기간에 학생 포털로 이의신청을 합니다.
2. 이의신청 기간이 지나면 학생 요청으로 성적을 바꾸지 않습니다.
3. 담당 교수가 입력 오류나 계산 오류를 찾으면 학과를 거쳐 성적정정원을 냅니다.
4. 중간고사처럼 학기 중에 받은 점수는 담당 교수가 정한 방법으로 확인합니다.

## 제17조(수강철회)

1. 수강철회는 별표 1의 기간에만 할 수 있습니다.
2. 학생 본인이 학생 포털에서 직접 신청합니다. 담당 교수의 승인은 필요 없습니다. 다른 사람이 대신 신청할 수 없습니다.
3. 철회한 과목은 성적표에 W로 남습니다.
4. 한 학기에 2과목까지 철회할 수 있습니다. 철회 후에도 12학점 이상을 들어야 합니다.
5. 철회가 장학금에 주는 영향은 이 규정에서 정하지 않습니다. 장학 담당 부서에 확인합니다.

## 제18조(수강 인원 초과)

1. 정원을 넘는 수강은 수강정정 기간에만 담당 교수가 승인할 수 있습니다.
2. 수강정정 기간 전에 초과 수강을 약속하지 않습니다.

## 제19조(학생 정보 보호)

1. 성적과 출석 정보는 학생 본인에게만 알려 줍니다. 보호자에게도 학생 본인의 서면 동의 없이 알려 주지 않습니다.
2. 학생에게 보내는 답장은 학교 메일 계정으로 보냅니다.
3. 이메일로 주민등록번호나 신분증 사본을 요구하지 않습니다.
