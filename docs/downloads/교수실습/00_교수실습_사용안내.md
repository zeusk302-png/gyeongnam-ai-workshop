# 교수 실습 자료 사용 안내

이 폴더의 대학, 과목, 교수, 학생, 논문, 학칙, 숫자는 모두 **교육용 가상 자료**입니다. 가온대학교는 실습을 위해 만든 대학입니다. 실제 경남대학교·경남테크노파크나 다른 기관의 규정과 자료가 아닙니다.

실습 속 교수는 **가상 교수 한도윤**입니다. 교양 과목 「데이터로 읽는 사회」 01·02분반을 맡고 있습니다. 때는 2026학년도 2학기 중간고사 직전, 2026-10-19(월) 아침입니다.

## 개인정보 약속

- 실습에는 이 폴더의 가상 자료만 씁니다.
- 실제 학생 이름, 학번, 성적, 메일, 강의평가 원문은 AI에 넣지 않습니다.
- 내 자료로 해 볼 때는 이름·학번·연락처를 먼저 지웁니다. 학교가 허용한 계정과 도구인지도 확인합니다.
- 가상 자료 안에도 전화번호, 학번, 건강 정보가 일부 들어 있습니다. AI가 이것을 걸러 내는지 보는 연습입니다.

## 쓰는 방법

1. 활동마다 표에 적힌 파일만 올립니다. 해설 파일은 올리지 않습니다.
2. 질문은 네 줄 공식(역할·자료·원하는 형태·하지 말 것)으로 씁니다.
3. 답을 받으면 '확인할 곳 한 가지'부터 원문과 맞춰 봅니다.
4. Gemini Notebook에는 02A~02E 다섯 파일만 소스로 넣습니다.
5. CSV가 엑셀에서 깨져 보이면 그대로 AI에 올리면 됩니다. 파일은 UTF-8입니다.
6. 학칙 파일은 실제 수업에서는 PDF일 때가 많습니다. 여기서는 같은 내용을 .md로 드립니다.

## 다른 AI 도구 짧게 보기

오늘 쓰는 세 도구 말고도 교수 업무에 쓸 만한 도구가 있습니다. 기능과 요금은 자주 바뀌니 쓰기 전에 확인하세요.

| 도구 | 잘하는 일 | 교수 업무 예 | 주의할 점 |
|---|---|---|---|
| ChatGPT | 대화, 글쓰기, 파일과 표 분석 | 강의 자료 초안, 데이터 요약 | 학교 계정 정책과 자료 저장 설정 확인 |
| Microsoft Copilot | Word·Excel·Outlook 안에서 작업 | 메일 요약, 엑셀 성적표 정리 | 학교가 Microsoft 365를 쓸 때 편함. 계정 종류 확인 |
| Perplexity | 웹 검색 결과를 출처 링크와 함께 답함 | 최신 정책·뉴스 찾기 | 링크를 직접 열어 원문 확인 |
| Consensus | 논문을 찾아 연구 결과를 요약 | "이 질문에 연구들이 뭐라고 하나" 훑기 | 요약만 보고 인용하지 말 것 |
| Elicit | 여러 논문에서 항목을 뽑아 표로 정리 | 문헌 검토 표 만들기 | 뽑힌 수치를 원문 쪽수와 대조 |

Gemini Notebook은 **내가 올린 자료** 안에서 답합니다. Perplexity, Consensus, Elicit은 **바깥 자료를 찾아** 답합니다. 없는 논문이나 틀린 수치가 섞일 수 있으니 원문을 꼭 확인합니다.
