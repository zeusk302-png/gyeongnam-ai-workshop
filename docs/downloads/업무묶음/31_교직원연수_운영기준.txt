문서명: 가온대학교·해솔연구원 문서 검토 공동연수 운영 기준
발행: 2026-11-06 08:30 / 작성 역할: 가상 공동연수 운영실
자료 구분: 교육용 가상 업무 자료. 기관명·행사·직원·승인·금액은 모두 허구다.

[P01] 행사 식별과 최초 계획
행사코드는 W1120이다. 행사는 2026-11-20 14:00~17:00에 진행하며 참가비는 없다. 최초 안내 장소는 가상연수관 201호다. 장소 변경은 시설 예약 확인과 운영책임자의 변경 승인 문서가 있어야 반영한다. 같은 건물의 11월 27일 연구윤리 특강은 행사코드 R1127로 별도 접수한다. 행사코드·날짜가 다른 문의를 제목에 '연수'가 들어간다는 이유로 합치지 않는다.
이번 연수는 공개 모집형 강연이 아니라 두 기관 직원의 공동 실습이다. 담당자가 인수인계를 받을 때 참가자 문의, 부서 추천, 좌석 배정, 장비 대여를 서로 다른 기록으로 읽어야 한다. 참가자가 답장을 기다리는 동안 내부 승인이 추가될 수 있으므로 메일 수신 시각과 확인 문서의 작성 시각을 함께 남긴다.

[P02] 정원과 기관별 배정
정원은 36명이며 가온대학교 24석, 해솔연구원 12석을 배정한다. 상대 기관의 남는 자리를 자동으로 가져갈 수 없다. 기관별 정원을 넘기는 신청이나 배정 이동은 운영책임자의 별도 서면 승인이 필요하다. 전체 확정 인원이 36명보다 적더라도 접수 검토·대기 안내 중인 자리가 있을 수 있으므로 단순 뺄셈으로 특정인에게 참가를 약속하지 않는다.
대기 순번은 기관별로 관리한다. 대기자에게 보낸 수락 요청은 참가 확정 통보와 다르다. 수락 회신 뒤 접수담당이 기존 신청과 중복 여부를 확인하고 확정 대장에 반영한다. 다른 사람에게 수락 요청을 전달하거나 기한이 지났다고 임의로 다음 순번을 확정하는 처리는 하지 않는다. 자리 비움과 대기 순서 적용 여부는 대장 담당자가 확인한다.

[P03] 최초 신청 일정과 접수 방법
최초 신청 기간은 2026-11-06 09:00~2026-11-10 15:00이다. 두 기관의 내부 승인 절차가 달라 이후 변경 승인에서 기관별로 다른 기한을 정할 수 있다. 연장 문서를 받으면 적용 기관·대상·종료 시각을 함께 확인한다. '전체 연장'이라는 전달 문장만으로 모든 신청자의 기한을 바꾸지 않는다.
가온대학교 직원은 기관의 공식 연수 신청 경로로 신청한다. 해솔연구원 직원은 소속 기관의 추천 확인과 공식 접수 확인을 거친다. 이메일 문의 수신, 추천서 제출, 오류 신고는 그 자체로 참가 확정이 아니다. 실제 신청 URL과 연락처는 이 가상 자료에 제공하지 않았다. 발송 전에 해당 기관의 공식 안내에서 확인하며 임의 주소를 만들지 않는다.

[P04] 취소·변경과 마지막 의사
취소 통보 기한은 2026-11-18 12:00이다. 참가자가 취소 의사를 보낸 기록과 접수담당이 명단에서 취소를 반영한 기록을 구분한다. 취소 처리 뒤 참가자가 다시 참석하겠다고 회신하면 복구 요청으로 접수하고, 기존 배정·대기 처리 상황을 확인한다. 마지막 메일이라는 이유만으로 처리된 취소를 자동 되돌리지 않는다.
동료에게 참가 자리를 넘기려는 요청도 기존 참가자의 상태와 새 참가자의 자격·기관별 배정·공식 접수를 확인해야 한다. 동료의 이름을 메일에 적었다는 이유로 교체 완료가 되지는 않는다. 아직 실행하지 않은 교체 요청을 철회했다면 본인 참가 유지 의사를 기록하고 현재 대장을 확인한다. 접수번호는 유지하여 같은 사람의 메일을 여러 건의 신규 신청으로 세지 않는다.

[P05] 대상 자격과 예외 심사
두 기관의 재직 직원이 대상이며 고용 형태만으로 임의 배제하지 않는다. 가온대학교의 기간제 직원은 담당 인사부서의 재직·신청 대상 확인을 받은 뒤 상태를 결정한다. 외부 용역업체 직원이나 일반인은 이번 모집 대상에 포함되지 않는다. 외부인에게 예외 참여를 허용하려면 운영책임자의 별도 승인 기록이 있어야 하며 현재 일반적인 외부인 예외 규정은 없다.
해솔연구원은 소속 부서 추천 확인이 필요하다. 추천 확인이 없는 신청을 승인됐다고 쓰거나, 추천 여부가 아직 확인 중인데 최종 불승인으로 종결하지 않는다. 한 명에게 내려진 개별 승인을 다른 사람이나 같은 기관 전체의 예외로 넓히지 않는다. 가족·동료가 이전에 받았다는 설명은 이번 승인 문서가 아니다.

[P06] 참여 기록과 이수 판단
기본 운영은 14:00~17:00 현장 참여와 실습 결과 세 종류 제출이다. 세 종류는 문의 처리표, 원문 확인 기록, 부서 전달 메일이다. 제출 확인 마감은 당일 17:30이며 교육담당이 제출 기준 충족 여부를 확인한다. 조퇴·비대면 참여·제출 시한 변경은 교육책임자의 개별 승인 범위를 확인한다. 미래 행사이므로 현재 참가 확정 인원을 실제 참석자나 이수자로 기록하지 않는다.
확인 문서 발급 여부·양식·발급 일정은 아직 정하지 않았다. 신청 확인 통지와 교육 이수 확인 문서는 다르다. 부서 보고에 참석 예정 사실을 적을 수는 있으나 발급받지 않은 이수증을 첨부했다고 쓰지 않는다. 승인된 조퇴 조건이 있어도 실제 참여와 제출 확인까지 끝난 것으로 표현하지 않는다.

[P07] 기기와 계정
참가자는 개인 노트북과 충전기를 준비한다. 기기담당이 임시 확보한 노트북은 6대지만, 점검 상태와 개인 배정 여부는 별도 대장을 따른다. 운영 준비용 장비와 참가자 대여 노트북을 혼동하지 않는다. 대여 승인된 참가자는 수령·반납 안내를 확인하며 해당 승인을 다른 사람에게 양도할 수 없다. 기기 수량과 대여 잔여 수량은 같은 말이 아니다.
대여료는 받지 않는다. 대여 기기에 유료 AI 계정이 함께 제공되는 것은 아니다. 참가자가 기관에서 허용한 계정으로 미리 접속하고 비밀번호나 인증 코드를 운영자에게 전달하지 않는다. 접속 제한 또는 사용량 제한이 있으면 원문 대조·짝 활동으로 참여한다. 유료 결제나 운영자 계정 공유를 필수 조건으로 두지 않으며, 남은 무료 질문 횟수를 기관이 보장하지 않는다.

[P08] 차량 이용
참가비 무료라는 조건으로 주차비 무료를 추정하지 않는다. 기관별 차량 관리 기준이 다르므로 별도 주차 승인 공지와 등록 완료 기록을 확인한다. 등록 요청서를 보낸 사실과 시설담당이 등록을 완료한 것은 다르다. 가온대학교 정기 등록 차량의 일반 이용 조건은 소속 기관 안내를 따른다. 행사 공지에서 정하지 않은 일반 요금·주차권 환급·부서 비용 보전을 만들어 안내하지 않는다.

[P09] 자료·녹화·사진
실습에는 제공된 가상 문서만 사용한다. 실제 학생·직원·거래처 자료는 이름을 지워도 업무 사정과 다른 식별 정보가 남을 수 있으므로 수업 입력으로 받지 않는다. 기관 내부 자료의 실제 허용 범위는 각 기관의 공식 기준을 확인한다. 교육 중 만든 답장은 담당자 검토를 위한 초안이며 실제 민원인에게 자동 발송하지 않는다.
녹화본 제공 여부는 최초 안내 시점에 미정이었다. 이후 승인 결과가 있으면 이번 회차에 적용되는 범위를 확인한다. 녹화 결정과 행사 사진 촬영·공개는 서로 다른 항목이다. 복습용 정적 자료가 제공된다고 비대면 이수가 자동 승인되는 것은 아니다.

[P10] 회신에 남길 근거와 담당
운영담당은 일정·모집 문안과 기관별 배정, 접수담당은 신청 상태·중복·변경 이력, 교육담당은 실습·조퇴·제출 기준, 기기담당은 개인 장비 배정, 시설담당은 동선·주차 등록, 기관담당은 재직·추천 확인을 맡는다. 확인이 필요한 항목은 무엇을 어느 역할에 물을지 구체적으로 적는다. 없는 회신 기한을 만들어 참가자에게 보장하지 않는다.
최신 승인 문서는 명시한 항목에서 최초 기준보다 우선한다. 참가자의 추측·친구의 경험·미발송 초안은 승인 문서가 아니다. 접수 대장은 대장 기준 시각까지 확인한 상태를 보여 주며, 이후 받은 메일만으로 확정 상태를 임의 변경하지 않는다. 안내할 문장에는 원문 문단과 처리 상태를 남겨 다른 담당자가 같은 결론을 검토할 수 있게 한다.
