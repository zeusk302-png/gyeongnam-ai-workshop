[L3] A002 중복 확인 / 11-10 13:20
같은 사람의 두 접수 기록을 A002 한 행으로 통합했다. 부서 이름의 표기만 달랐으며 최초 유효 신청의 참가 확정 상태를 유지한다. 두 번째 제출을 별도 사람이나 별도 좌석으로 세지 않는다. 참가자에게 새 취소 신청을 요구한 기록은 없으며 대기 순번으로 낮춘 것도 아니다.

[L4] A003 연락처 정정 확인 / 11-10 13:40
공식 수정 창구 CONTACT-003의 확인을 받아 연락 경로 정정을 반영했다. 참가번호 A003과 참가 확정 상태는 유지한다. 실제 주소는 이 가상 대장에 넣지 않았다. 일반 이메일로 실제 연락처를 다시 보내라고 요구하지 않고 공식 확인 결과로 안내한다.

[L5] A004 교체 요청 확인
본인 참가 확정은 유지한다. 동료의 공식 신청·재직 확인·교체 승인은 아직 없다. 교체 상담과 요청만으로 A004 취소나 새 참가자 확정을 실행하지 않았다. 새 사람의 참가 ID를 임의로 만들어 표에 추가하지 않는다.

[L6] A005 문의 철회 확인
공식 취소·교체 실행 기록은 없다. 최신 메일에서 교체 문의를 거두고 본인이 참가하겠다는 뜻을 확인했다. 대장은 A005 확정 상태를 유지한다. 이미 취소된 참가를 복구한 사례로 표시하지 않는다.

[L7] 다른 행사와의 연결 범위

[L9] 담당 교대 메모
