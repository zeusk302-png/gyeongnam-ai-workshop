이 문서는 행사가 종료되었다고 가정한 가상 실적이다.
실제 기관의 실적이나 예산, 만족도 조사 결과가 아니다.

1. 지표 정의
- 신청 인원: 신청을 완료한 사람 수
- 실제 참여 인원: 현장 참여를 확인한 사람 수
- 이수 인원: 실제 참여 인원 중 가상 실습 결과물 5종을 모두 제출한 사람 수
- 이수율: 이수 인원÷실제 참여 인원×100
- 집행액: 행사 운영에 실제 사용했다고 가정한 총액
- 참여자 1인당 집행액: 집행액÷실제 참여 인원
- 만족도: 응답자만을 대상으로 계산한 5점 만점 평균이며 원자료는 제공되지 않음

3. 서술에 사용할 수 있는 기록
- 이번 회차는 이메일, 회의 정리, 예산 검산, 자료 근거 확인, 결과 보고서 작성 실습을 진행했다.
- 이번 회차 운영 메모에는 '시작 시 일부 참가자의 로그인이 지연되어 2인 1조 활동을 병행했다'고 기록되어 있다. 인원 수와 지연 시간은 기록되어 있지 않다.
- 미이수자 4명의 미이수 사유는 수집하지 않았다.
- 이번 집행액 845,000원은 준비 단계에서 곱셈 오류를 수정한 예산 총액과 같다.

4. 보고서 작성 조건
- 대상 독자는 가상 기관의 부서장이다.
- 이전 회차 대비 실제 참여 인원, 이수율, 집행액의 변화를 앞부분에 제시한다.
- 이수율의 분모는 반드시 실제 참여 인원을 사용한다.
- 인원 증감률과 집행액 증감률은 이전 회차를 기준으로 계산한다.
- 비율 차이는 퍼센트포인트(%p)로 표시한다.
- 금액은 원 단위, 비율은 소수점 첫째 자리까지 표시하되 계산은 반올림 전 값을 사용한다.
- 만족도 변화의 원인, 미이수 사유, 도구별 생산성 개선 효과는 이 자료만으로 확정할 수 없다.
- 사전 로그인 점검과 보충 실습 안내는 개선 '제안'으로 쓸 수 있지만 이미 시행한 일처럼 쓰지 않는다.
