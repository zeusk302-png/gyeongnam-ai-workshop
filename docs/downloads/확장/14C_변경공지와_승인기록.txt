[C1] 접수한 변경 요청
2026-10-21 16:00 운영담당이 신청 기간 연장 요청을 제출했습니다. 일부 부서에서 내부 업무 일정 때문에 최초 마감일까지 참가 의사를 모으기 어렵다는 문의가 왔습니다. 연장 요청은 2026-10-23 18:00 마감을 2026-10-26 18:00으로 바꾸자는 내용입니다. 정원 확대와 취소 기한 변경은 요청하지 않았습니다.

같은 요청 묶음에 시설담당의 301호 사용 제안과 기기담당의 보유 노트북 임시 사용 검토가 들어 있었습니다. 요청 묶음이 하나라는 이유로 세 항목을 한꺼번에 승인하지 않았습니다. 아래 C2, C3, C4에 각각의 결정과 확인되지 않은 사항을 적었습니다.

2026-10-22 13:20: 가상 교육운영실장이 교육 당일 보유 노트북 4대의 임시 사용을 승인. 참가자 개인별 배정은 운영담당 확인 후 별도 안내.

11:30의 기기 점검은 4대의 임시 사용 가능 여부에 관한 기록입니다. 신청한 특정 참가자에게 기기를 배정했다는 기록이 아닙니다. 09:10의 장소 추가 확인 요청은 장소 변경의 조건부 승인이 아니라 검토를 계속하라는 요청입니다.

[C2] 승인 사항 1 — 신청 마감 연장
결정: 승인
승인 시각: 2026-10-22 10:40
변경 전: 2026-10-23 18:00
변경 후: 2026-10-26 18:00
적용 대상: 이번 워크숍의 참가 신청 마감 안내
관련 구공지: 문서 A의 A3, A5-2, 아래 C5의 포털 요약 문안

본 통보 이후 신청 마감을 안내할 때에는 2026-10-26 18:00을 사용합니다. 10월 24일에 참가 신청을 하려는 문의는 연장된 신청 기간 안에 해당합니다. 다만 기간 안이라는 것과 참가가 확정됐다는 것은 다릅니다. 참가 확정 여부와 잔여석, 대기 순번은 운영담당의 접수 명단 확인이 필요합니다. 마감 연장만으로 정원이 30명보다 늘어난 것은 아닙니다.

이미 접수한 신청을 취소하고 다시 신청하라는 결정은 없습니다. 접수 경로와 개인별 처리 상태를 확인하려는 문의는 운영담당에게 전달합니다. 마감 이후 별도 신청이나 예외 승인을 미리 허용한 기록도 없습니다. 승인된 것은 신청 기한의 연장 한 건입니다.

[C2-1] 변경하지 않는 일정
취소 통보 기한은 2026-10-28 12:00으로 유지합니다. 신청 마감을 연장했다고 취소 기한도 같은 일수만큼 늦추지 않습니다. 교육은 2026-10-30 14:00~17:00에 진행하며 일정 변경은 없습니다. 기존 준비 업무의 마감일도 자동으로 연장되지 않습니다. 실습 자료 완성 2026-10-21, 수정 예산표 공유 2026-10-23의 상태는 해당 업무 기록으로 확인합니다.

[C3] 장소 변경 제안 — 미승인
제안 내용: 가상연수관 201호 대신 301호를 사용하자는 의견.
처리 상태: 추가 확인 중, 장소 변경 미승인.
확정 장소: 가상연수관 201호 유지.
확인할 내용: 301호의 예약 가능 여부, 실습에 필요한 전원 배치, 참가자 동선.

시설담당은 공간 여유를 이유로 301호를 제안했으나 위 확인과 변경 승인은 끝나지 않았습니다. 301호라고 적힌 내부 좌석 그림은 검토 자료로 보관하고 참가 안내에 쓰지 않습니다. 안내문 제목, 길 안내, 참가자 답장에는 현재 확정된 201호를 적습니다. 후속 승인이 있으면 별도 통보할 예정이며, 이 문서에는 승인 예정일이나 변경을 보장하는 내용이 없습니다.

건물 출입이나 이동 편의와 관련한 개인별 요청은 시설담당에게 확인할 수 있도록 운영담당이 전달합니다. 이 제안서에는 승강기 운영 시간, 주차장 연결 경로, 별도 출입 지원의 확정 답변이 포함되어 있지 않습니다. 시설 문의에 공간이 넓다는 설명만으로 편의를 보장하지 마십시오.

[C4] 승인 사항 2 — 노트북 4대 임시 확보
결정: 교육 당일 보유 노트북 4대의 임시 사용 승인.
승인 시각: 2026-10-22 13:20

기기담당의 기본 동작 점검 결과를 확인했습니다. 4대는 확보한 총수량이며 현재 남은 수량이나 특정 신청자의 확보 수량을 뜻하지 않습니다. 운영담당이 개인 노트북이 없는 참가자의 요청과 확정 참가 명단을 대조한 뒤 배정 여부를 회신합니다. 신청자가 먼저 문의했다는 이유로 선착순 배정이 확정됐다고 안내하지 않습니다. 우선 배정 기준과 초과 수요 처리 방식은 아직 결정된 기록이 없습니다.

기기를 받지 못하는 경우에는 A4의 짝 활동이나 시연 참여 방법을 안내할 수 있습니다. 휴대전화만 가져와도 모든 활동이 문제없다고 약속하거나, 대여 요청서를 보냈다는 사실만으로 개인 노트북을 가져오지 않아도 된다고 확답하지 않습니다. 개인별 배정 안내를 받은 뒤 준비물을 정하도록 회신해 주시기 바랍니다.

[C4-1] 기기 인계와 계정 정리 요청
운영담당은 배정 결과를 교육담당과 기기담당에게 공유하고, 기기담당은 당일 반납 때 참가자의 계정 로그아웃과 내려받은 파일 정리를 안내할 수 있도록 준비합니다. 계정 비밀번호나 인증 코드를 수집하지 않습니다. 기기 번호와 배정표, 실제 인수·반납 기록은 이 통보에 붙어 있지 않습니다. 기기 확보 승인이 인수 완료를 뜻하지 않습니다.

이번 확보는 기존 보유 노트북을 이용하며 B1의 준비 예산 845,000원은 변경하지 않습니다. 예산표의 시청각 장비대여 2개, 50,000원과 별도로 관리합니다. 개인별 문의에 내부 예산표나 기기 자산 관리 메모를 덧붙여 보낼 필요는 없습니다.

[C5] 구공지에서 고칠 세 곳
운영담당은 아래 세 곳의 신청 마감 표시를 같은 날짜와 시각으로 맞춰 주시기 바랍니다. 수정할 문장과 주변 문장의 취소 기한, 장소, 정원은 함께 읽어 잘못 바뀌지 않았는지 확인합니다.

이 포털 문안은 구공지의 보관 사본입니다. 실제 게시 주소와 수정 완료 화면은 첨부하지 않았습니다. 노트북 지참 안내는 기기별 배정이 끝나지 않았으므로 그대로 둡니다.

운영담당: 위 세 곳을 2026-10-22 17:30까지 수정하고 변경 사실을 각 부서 교육담당자에게 전달해 주시기 바랍니다. 본 통보 시각 현재는 수정 요청 상태이며, 세 곳을 모두 바꿨다는 완료 회신은 없습니다. 한 곳을 수정한 기록으로 전체 공지 수정을 완료 처리하지 않습니다.

[C7] 공지 전달 시 적용할 범위
