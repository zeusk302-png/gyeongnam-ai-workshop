# 업무실습 사용 안내

이번 수업은 **업무실습**으로 시작합니다. 여러 번 주고받은 메일, 정정 발언이 남은 회의록, 구매 요청표, 날짜가 다른 공지, 출석·설문·지출 기록을 읽고 다음 담당자에게 넘길 문서를 만듭니다. 원자료는 8개, 전체 분량은 약 6만 자입니다. 모두 교육을 위해 만든 가상 자료이며 실제 기관의 문서나 실적이 아닙니다.

짧은 예제로 도구 조작부터 익히고 싶으면 웹페이지에서 **기본연습**을 선택하세요. 업무실습은 기본연습의 문장만 늘린 자료가 아닙니다. 여러 문의를 한꺼번에 처리하고, 변경 승인과 중간 집계를 구별해야 하므로 자료와 확인할 답이 다릅니다. 한 활동에서 두 버전을 모두 할 필요는 없습니다.

## 파일 넣는 순서

Gemini는 업무마다 새 대화를 엽니다. 메일에는 11번, 회의에는 12번, 구매 검토에는 13번 자료를 넣으세요. 웹의 첫 질문에는 해당 원문이 포함되어 있어 한 번에 복사할 수 있습니다. 수정할 때에는 같은 대화에서 이어갑니다.

NotebookLM에는 새 노트북을 만들고 아래 **네 파일을 각각 소스로** 추가합니다.

| 파일 | 작성 시점 | 읽을 때 볼 부분 |
|---|---|---|
| `14A_NotebookLM_교육운영안내_상세.txt` | 2026-10-16 | 최초 안내의 신청·취소·준비물 조건 |
| `14B_NotebookLM_운영회의_업무인계.txt` | 2026-10-20 | 준비 업무의 마지막 처리 기록과 남은 확인 |
| `14C_변경공지와_승인기록.txt` | 2026-10-22 | 승인된 변경, 미승인 제안, 구공지 수정 대상 |
| `14D_참가문의_접수목록.txt` | 2026-10-22 | 참가자 문의 12건과 내부 문의 2건 |

날짜가 늦다는 이유만으로 모든 내용을 새 조건으로 받아들이지 마세요. 요청을 접수한 것인지, 승인한 것인지, 실제로 처리까지 마친 것인지 문장과 기록을 함께 봅니다. 기본연습용 04A·04B, 정답 파일, 복사 질문 모음, 15번 행사 결과 자료는 이 노트북에 넣지 않습니다. D15는 공통 회신 확인 항목이며 문의 14건에 더해 세지 않습니다.

Claude에는 15번 자료를 처음 한 번 넣습니다. 이후 같은 대화에서 목차, 보고서 초안, 문장 수정, 전달 메일을 이어서 만듭니다. 보고서는 본문 1,200~1,600자 정도에 표와 계산 메모를 별도로 두고, 편집기에서 1~2쪽으로 읽기 좋은지 확인합니다. 전달 메일은 본문 350~500자로 따로 작성합니다. 전체 보고서를 메일 분량으로 줄이거나 덮어쓰지 마세요.

휴식 10분을 포함해 총 180분입니다. 문서를 처음부터 끝까지 소리 내어 읽기보다 맡은 업무와 관련된 메일, 표, 승인 기록부터 살펴보세요. 시간이 부족하면 해당 활동을 기본연습으로 바꾸고 다음 도구의 시작 시각에 맞춰 진행합니다. 오디오 요약은 시간과 사용량이 남을 때만 선택합니다.

## 직접 처리와 도구 사용을 비교할 때

첫 문의를 읽는 90초는 어디서 시간이 걸리는지 알아보는 시간입니다. 답장을 완성하지 못하면 결과 기록지에 ‘미완성’이라고 적으세요. 직접 한 건을 읽은 시간과 도구로 여섯 건을 처리한 시간을 곧바로 나눠 절감률을 계산하지 않습니다. 처리 건수와 결과의 완성 정도가 다르기 때문입니다.

`08_참가자_결과기록지.md`에는 자료를 준비한 시간, 직접 작성하거나 질문을 입력한 시간, 답변을 기다린 시간, 확인하고 고친 시간을 나눠 적습니다. 남아 있는 오류도 함께 적으세요. 같은 건수와 같은 완료 기준으로 끝까지 처리한 경우에만 전체 시간을 비교할 수 있습니다. 이번 수업에서 그런 조건을 맞추지 못했다면 걸린 시간과 어려웠던 부분만 기록하면 됩니다.

## 이전 캡처를 보는 방법

화면 아래의 자료 버전과 촬영 설명을 먼저 확인하세요. 기본연습 또는 이전 자료로 촬영한 화면은 버튼 위치와 조작 순서를 참고하는 데 사용합니다. 그 화면의 문의 건수, 신청 마감, 예산 합계, 보고서 길이를 이번 업무실습의 답으로 옮기지 마세요. 새 업무실습 결과는 현재 원문과 `17_확장본_검토기준.md`로 확인합니다.

무료 계정의 한도에 걸리면 받아 둔 답변을 원문과 비교하거나 짝 활동으로 이어갑니다. 새 대화에 같은 자료를 반복해서 보내지 마세요. [무료 계정 사용 안내](../10_무료계정_한도와_실습사용법.md)에서 사용량 확인 위치와 대체 진행 방법을 볼 수 있습니다.
