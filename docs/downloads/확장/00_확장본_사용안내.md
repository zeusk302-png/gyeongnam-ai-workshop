# 확장본 사용 안내

이 자료는 실제 업무 문서의 구성을 본떠 만든 **교육용 가상 자료**입니다. 기관의 실제 문서나 실적이 아닙니다. 입문용의 숫자와 업무 기준은 그대로 두고, 주고받은 메일·문서 관리 정보·업무 배경·회의 발언·실적 집계 방법을 더했습니다.

## 어떤 버전을 고를까요?

| 입문용 | 확장본 |
|---|---|
| 짧은 자료로 질문을 보내고 답변을 확인 | 여러 메일과 회의 기록을 읽고 답장·회의록·보고서 작성 |
| 날짜·숫자·업무 기준을 짧게 정리 | 배경 설명과 반복되는 내용 사이에 날짜·숫자·업무 기준이 섞여 있음 |
| 처음 쓰는 도구이거나 따라 하는 데 시간이 필요할 때 | 도구 사용에 익숙하고 긴 문서로 연습하고 싶을 때 |

같은 활동을 두 번 할 필요는 없습니다. 세 도구 중 **익숙한 도구 하나만 확장본으로 선택**해도 충분합니다. 강의 웹페이지의 ‘입문용 / 확장본’을 누르면 자료와 첫 질문에 포함된 원문, 다운로드 파일이 함께 바뀝니다. NotebookLM·Claude 실습 도중에 버전을 바꾸면 자료를 넣는 시작 단계로 돌아갑니다.

## 파일과 입력 방법

| 파일 | 자료 형식 | 넣는 곳 |
|---|---|---|
| 11 | 학생 문의 메일 스레드·접수 메모·업무 기준 | Gemini 학생 답장 활동의 새 대화 |
| 12 | 발언과 보충 메모가 섞인 상세 회의 기록 | Gemini 회의 정리 활동의 새 대화 |
| 13 | 산출 근거·집행 기준·6행 예산표 | Gemini 예산 검산 활동의 새 대화 |
| 14A | 참가자용 상세 교육 운영 안내 | NotebookLM 새 노트북의 소스 A |
| 14B | 담당자용 회의·업무 인계 문서 | 같은 노트북의 소스 B |
| 15 | 집계표·현장 메모·설문 전달 사항 | Claude 목차 활동의 새 대화 |

Gemini·Claude에서는 강의 웹페이지에서 자료와 질문을 한 번에 복사할 수 있습니다. NotebookLM에는 **14A와 14B 두 파일만** 넣으세요. 입문용 04A·04B나 15 결과 자료, 이 안내, 프롬프트, 검토 기준을 함께 넣지 않습니다. Claude에는 15를 한 번 넣은 뒤 같은 대화에서 초안을 쓰고, 문체와 분량을 고치고, 잘못 쓴 내용이 없는지 확인합니다.

## 3시간 안에서 진행하기

- 0–20분: 강사 소개와 접속 점검, 자신에게 맞는 자료 버전 선택
- 20–65분: Gemini 각 활동의 첫 2~3분에 자료를 훑어본 뒤 질문 보내기
- 65–70분: 휴식
- 70–115분: NotebookLM에 넣을 A·B의 제목·기준일·목차를 먼저 읽고 두 자료에 관해 질문하기
- 115–120분: 휴식
- 120–165분: Claude에 넣을 자료의 집계표·실적 집계 방법·현장 메모를 먼저 읽고 보고서 목차부터 작성하기
- 165–180분: 답변과 원문을 비교한 내용을 기록하고 내 업무에 써볼 방법 적기

문서를 처음부터 끝까지 읽을 필요는 없습니다. ‘어떤 기준이 답장을 결정하는가?’, ‘무엇이 결정이고 무엇이 제안인가?’, ‘계산의 분모는 무엇인가?’를 생각하면서 필요한 부분부터 읽으세요. 읽기에 시간이 많이 걸리면 해당 활동은 입문용으로 바꿔도 됩니다. 전체 시간은 휴식 10분을 포함해 180분입니다.

## 원문을 볼 때 유의할 점

1. 14A·14B는 행사 전 2026-10-16 기준 자료, 15는 행사 후 2026-10-31 기준 자료입니다. 계획·마감일과 실제 결과를 섞지 않습니다.
2. 12의 회의에 승인 예산 총액이 등장해도, 13에서는 표를 독립적으로 검산합니다. 알고 있는 총액에 맞춰 계산식을 거꾸로 끼워 맞추지 않습니다.
3. 자료가 길어져도 현재 여석·주차 요금·미이수 사유는 적혀 있지 않습니다. 이런 내용은 추측하지 말고 확인 필요로 남깁니다.
4. 웹페이지의 캡처는 대부분 입문용 자료로 실습한 화면입니다. 확장본 화면이 없는 단계에서는 ‘입문용 자료로 실행한 화면 참고’를 펼쳐 버튼 위치와 답변을 확인하는 방법을 살펴보세요.
5. `17_확장본_검토기준.md`는 결과를 만든 뒤 대조합니다. NotebookLM 소스로 넣지 않습니다.
