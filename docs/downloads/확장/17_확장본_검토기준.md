# 업무실습 검토 기준

먼저 결과를 만든 뒤 이 파일을 펼쳐 비교하세요. 표현이 똑같을 필요는 없습니다. 날짜·금액·업무 상태를 바르게 읽었는지, 받은 요청에 맞는 문서를 만들었는지를 확인합니다. 이 파일을 NotebookLM 소스로 넣지 않습니다.

업무실습과 기본연습은 자료와 질문이 다릅니다. 기본연습의 07번 정답이나 09번 짧은 보고서를 이번 업무실습 답안으로 사용하지 마세요. 아래의 문서 번호와 문단·발언 시각은 업무실습 원자료를 가리킵니다.
