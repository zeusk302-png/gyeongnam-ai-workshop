# 3시간 AI 업무 활용 워크숍 · 실습자료

이 폴더의 인물·기관·행사·업무 기준·날짜·금액·실적은 모두 **교육을 위해 만든 가상 데이터**입니다. 실제 경남대학교·경남테크노파크 또는 다른 기관의 정책이나 실적을 나타내지 않습니다. 실습 결과는 초안이며 실제 업무에 적용할 때에는 해당 기관의 원문과 담당자 확인이 필요합니다.

수업에서는 가상 기관의 **「교직원 AI 업무 활용 워크숍」**을 준비하고 마무리합니다. Gemini로 학생에게 보낼 답장과 회의록을 쓰고 예산표를 확인합니다. NotebookLM에서는 교육 안내와 운영 메모를 읽고 참가자의 질문에 답합니다. Claude로는 행사가 끝난 뒤 제출할 결과 보고서를 씁니다. 학생 문의도 연습을 위해 만든 사례입니다.

## 진행 방법

1. 자료와 질문을 복사해 해당 도구에 붙여 넣습니다. NotebookLM에는 **04A와 04B 두 자료만** 소스로 추가합니다. 답안이나 프롬프트 모음은 소스로 넣지 않습니다.
2. 답변의 날짜와 숫자를 원문과 맞춰 보세요. 회의에서 제안만 한 일을 결정된 것처럼 쓰지는 않았는지도 확인합니다.
3. 실제 실습 화면은 자신이 입력한 가상 자료와 결과가 보이는 부분만 캡처합니다. 계정 이름·이메일·다른 대화·탭은 제외하거나 가립니다.
4. 답장이나 보고서를 직접 써본 뒤, 강사와 함께 정답 파일을 열어 비교합니다.

화면이 캡처와 달라도 자료를 넣고, 질문을 보내고, 답변을 확인하는 순서로 따라오면 됩니다. 소스 파일 첨부가 불가능하면 자료 내용을 복사해 텍스트 소스로 추가합니다. 로그인이나 이용 한도로 실습이 어려우면 2인 1조로 진행하거나 강사 화면의 답변에서 잘못된 내용을 찾아봅니다.

## 답변을 받으면 이것부터 확인하세요

- 이메일: 예외 승인이나 수강 변경을 확정하지 않았는가?
- 회의록: 미정 안건을 결정 사항으로 바꾸지 않았는가?
- 예산: 입력된 금액의 합계와 수량×단가로 검산한 합계를 구분했는가?
- 참가자 질문에 답하기: 자료에 없는 주차 요금을 지어내지 않았는가?
- 보고서: 비율의 분모, 증감률과 퍼센트포인트를 구분했는가?

문의·보고·배포는 모두 가상 연습입니다. 이메일 발송이나 실제 기관 문서 제출은 포함하지 않습니다.
