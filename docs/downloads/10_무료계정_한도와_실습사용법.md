# 무료 계정 한도와 실습 사용법

공식 안내 확인일: 2026-09-27

개인 무료 계정 기준으로 설명합니다. 학교·직장 계정은 기관의 라이선스나 관리자 설정에 따라 이용 범위가 다를 수 있습니다.

수업 전에 남은 사용량을 확인하세요. 긴 문서나 긴 대화는 사용량을 더 많이 쓸 수 있습니다. 제한 알림이 뜨면 다시 사용할 수 있는 시간을 확인하세요.

## 수업 전 준비

1. 각 도구에 본인 계정으로 로그인하세요. 유료 결제나 무료 체험은 신청하지 않아도 됩니다.
2. 설정의 사용량 메뉴나 제한 알림을 확인하세요. 수업 전에 이미 사용한 계정은 도중에 한도에 걸릴 수 있습니다.
3. 수업은 업무실습 자료로 진행합니다. 조작을 먼저 익히거나 남은 사용량이 적으면 짧은 기본연습 자료를 선택하세요.
4. 제공된 질문을 한 번 보내고 답변을 끝까지 읽으세요. 고칠 부분이 있을 때만 추가로 요청하세요.
5. 한도에 걸리면 받은 답변을 저장하세요. 아래 안내에 따라 원문과 비교하거나 짝과 진행하면 됩니다. 새 대화나 새 노트북을 열어도 사용량 한도가 초기화되지는 않습니다.

## 수업에서 보낼 질문 수

여기에 적힌 질문 횟수는 수업에서 보낼 횟수입니다. 남은 사용량에 따라 도중에 제한될 수 있습니다. 답변과 원문을 비교하거나 직접 계산하는 활동은 계속 진행하세요.

업무실습은 Gemini 3회와 필요할 때 수정 1회, NotebookLM 채팅 3회, Claude 4회로 총 10~11회 질문합니다. 계정에 남은 사용량과 문서 길이에 따라 도중에 제한될 수 있습니다. 마지막 업무 계획은 기록지에 직접 쓰고, 오디오는 시간이 남으면 만들어 보세요.

## Gemini

무료는 표준 사용량 한도. 고정 질문 횟수는 현재 공식 안내에 공개되지 않았습니다.

컴퓨팅 기반 한도 · 5시간마다 갱신 · 주간 한도 적용

### 사용량은 어디서 확인하나요?

웹 왼쪽 아래 설정 → 사용량 한도(Usage Limits). 메뉴가 다르면 한도 도달 알림의 다음 갱신 시각을 확인합니다.

### 공식 안내에 나온 한도

- 2026-05-17 변경 안내 기준입니다. 질문 복잡성·모델·기능·누적 대화 길이가 사용량에 영향을 줍니다.
- 무료 문맥 용량은 공식 표상 32k 토큰입니다. 문자 수나 무료 질문 횟수와 같은 단위가 아닙니다. 이번 수업에서는 여러 원자료를 한꺼번에 넣지 않습니다.

### 무료 계정으로 실습하기

1. 무료로 선택할 수 있는 기본 모델로 시작하세요. 모델을 고를 수 있다면 짧은 답장·요약에는 Flash-Lite 계열과 기본 사고 수준을 선택하세요. 계정에 따라 모델 이름은 다를 수 있습니다.
2. 문의 묶음을 한 번에 넣고 처리표와 답장 세 건을 받습니다. 업무 기준과 마지막 메일을 대조한 뒤 필요한 경우에만 한 번 수정합니다.
3. 회의와 예산 실습은 각각 새 대화를 열고 해당 자료만 넣으세요. Google Drive나 메일을 연결할 필요는 없습니다.
4. 결정된 일과 미정인 일, 담당자와 마감일을 원문과 비교하세요. 예산 합계도 직접 계산하세요. 이번 실습에서는 Deep Research나 이미지·동영상 생성은 사용하지 않습니다.

### 질문 수를 줄여 진행하려면

업무실습은 문의 묶음 1회·회의 1회·구매 검토 1회, 필요하면 답장 수정 1회를 더해 총 3~4회 질문합니다. 기본연습은 기존 5회 또는 줄인 4회로 진행합니다.

- 문의·회의·구매 요청은 각각 새 대화에 한 번씩 보냅니다. 수정이 필요하면 문의 답장에만 한 번 더 요청하세요(총 3~4회).
- 답장 세 건 중 한 건, 회의의 중간 정정, 구매표의 서로 다른 오류 세 건은 직접 확인하세요. 기본연습을 선택했다면 해당 화면의 짧은 자료로 확인합니다.
- 긴 자료는 첫 질문에 한 번만 넣습니다. 더 긴 답변을 반복해서 요청하지 말고, 필요한 행이나 문장만 고칩니다.

### 한도에 도달하면

한도 알림에서 다시 쓸 수 있는 시간을 확인하세요. 이미 받은 답변이나 실습 예시 화면을 원문과 비교하고, 예산은 계산기로 다시 계산하세요. 모델을 바꿔 계속 쓸 수 있는지는 계정에 표시된 안내를 확인하세요.

## NotebookLM · Gemini Notebook

무료는 표준 사용량 한도. 채팅·오디오의 고정 무료 횟수를 새 정책에서 공개하지 않습니다.

2026-09-02부터 컴퓨팅 기반 · 5시간 갱신 · 주간 한도 적용

### 사용량은 어디서 확인하나요?

웹 오른쪽 위 설정 → 사용량(Usage). 채팅 아래의 잔여 사용량·갱신 시각과 Studio 생성의 예상 사용량도 확인합니다.

### 공식 안내에 나온 한도

- 현재 공식 저장 개수 표: 사용자당 노트북 100개, 무료 노트북당 소스 50개. 하루 생성 가능 횟수와는 다른 한도이며 변경될 수 있습니다.
- 소스 안내: 소스당 50만 단어(영문 기준), 로컬 업로드 파일당 최대 200MB. 이번 수업은 노트북 1개와 업무실습 TXT 소스 4개(기본연습은 2개)만 사용합니다.

공식 안내 두 곳의 내용이 다릅니다. 요금제 표에는 ‘채팅 50회/일·오디오 3회/일’이 남아 있지만, 9월 2일 변경 안내는 계산량 기준으로 설명합니다. 이 수업에서는 새 안내를 따르며, 실제 사용 가능 여부는 계정 화면에서 확인하세요.

### 무료 계정으로 실습하기

1. 새 노트북에 업무실습 14A·14B·14C·14D를 각각 넣으세요. 기본연습을 고르면 04A·04B만 넣습니다. 두 버전은 섞지 마세요.
2. 소스 네 개의 문서명과 작성일을 확인하세요. 질문 모음과 검토 기준은 소스로 넣지 않습니다.
3. 업무실습은 인계표·최신 FAQ·문의 14건 처리표를 순서대로 질문합니다. 같은 소스로 계속 진행하세요.
4. 최초 공지와 승인된 변경을 함께 읽고 신청 마감과 대여 조건을 확인하세요. 주차 금액과 녹화 제공 등 확답할 수 없는 내용도 구분합니다.
5. 오디오는 시간이 남고 사용량이 충분할 때만 만듭니다. 30초 인계 설명으로 대신해도 됩니다.

### 질문 수를 줄여 진행하려면

업무실습은 노트북 1개·14A~14D 소스 4개·채팅 3회입니다. 기본연습은 04A·04B 소스 2개로 채팅 3~5회입니다. 오디오는 선택입니다.

- 인계표·최신 FAQ·문의 처리표의 첫 질문만 보냅니다(업무실습 3회).
- 추가 질문 대신 인용을 열어 변경 승인, 미승인 제안, 미처리 문의를 직접 비교하세요. 기본연습은 요약·FAQ·주차 질문만 보냅니다.
- 소스 업로드와 인용 열기는 이 채팅 횟수 계산에서 제외했지만 사용량이 전혀 들지 않는다는 뜻은 아닙니다. 오디오는 생략합니다.

### 한도에 도달하면

이미 받은 답변을 네 문서와 비교하세요. 먼저 14C의 승인된 변경을 읽고, 14D에서 바로 답할 수 있는 문의와 담당 확인이 필요한 문의를 나눕니다. 옆 사람과 함께 진행해도 됩니다.

## Claude Free

고정 메시지 횟수는 공개하지 않습니다. 수요와 질문·첨부·대화 길이에 따라 달라집니다.

5시간 세션 한도 · 실제 화면의 재개 가능 시각 확인

### 사용량은 어디서 확인하나요?

사용량 메뉴가 보이지 않으면 대화에 뜨는 한도 알림에서 다시 쓸 수 있는 시간을 확인하세요.

### 공식 안내에 나온 한도

- 짧은 질문과 긴 문서 요청은 같은 양을 소비하지 않습니다. 긴 첨부·누적 대화·선택 모델·도구 사용이 영향을 줍니다.
- 사용량이 초기화되면 이전 대화를 이어서 사용할 수 있습니다. 새 대화를 열어도 계정의 사용량 한도가 초기화되지는 않습니다.

### 무료 계정으로 실습하기

1. 새 대화에 업무실습 15번 전체 자료가 포함된 첫 질문을 넣으세요. 기본연습은 05번 자료를 씁니다. 결제나 유료 파일 생성 기능은 필요하지 않습니다.
2. 목차 다음에 전체 보고서, 문체 수정, 별도 요약 메일을 같은 대화에서 요청하세요. 원자료는 다시 붙이지 않습니다.
3. 답변과 비교 표를 메모나 문서에 복사해 저장하세요. DOCX·PPTX 파일을 자동으로 만들 필요는 없습니다.
4. 참여 인원·이수율·증감률·퍼센트포인트를 직접 계산하세요. 만족도 응답 수가 맞는지, 자료에 없는 내용을 단정하지 않았는지도 확인하세요. AI가 “검증 완료”라고 해도 이 과정은 직접 진행하세요.
5. 긴 자료를 한 번에 입력하기 어렵거나 사용량이 부족하면 기본연습으로 바꾸고 새 대화에서 시작하세요. 자료를 바꾸어도 계정 사용량은 초기화되지 않습니다.

### 질문 수를 줄여 진행하려면

업무실습은 자료 정리와 목차·보고 초안·문체 수정·별도 전달 메일의 총 4회입니다. 마지막 수치 확인은 직접 합니다. 기본연습은 기본 6~7회 또는 줄인 4회로 진행합니다.

- 업무실습은 네 단계의 첫 질문만 보냅니다. 별도의 검산 질문이나 최종 확인 질문은 보내지 않습니다.
- 출석·설문·지출을 직접 계산하고, 검토 기준 17번과 비교하세요. 전체 보고서는 보관하고 짧은 전달 메일만 따로 만듭니다.
- 이번 회차 설문 원응답은 제공되지만 이전 회차 원응답은 제공되지 않았습니다. 보고서가 둘을 혼동하지 않았는지 확인하세요.

### 한도에 도달하면

마지막으로 받은 보고서나 목차를 저장하고 15번 자료와 17번 검토 기준을 보며 직접 완성하세요. 기본연습의 09번 보고서는 분량과 자료가 다르므로 새 업무실습의 답안으로 쓰지 않습니다.

## 결과 기록

직접 실행했는지, 짝과 함께 했는지, 강사 화면이나 예시 화면을 보고 확인했는지 적으세요. 답변에서 고친 문장과 직접 계산한 숫자도 남겨 두세요. 한도에 걸리면 이미 받은 답변이나 예시 화면을 원문과 비교하며 계속 진행할 수 있습니다.

한도와 메뉴는 확인일 이후 바뀔 수 있습니다. 예시 화면만으로는 내 계정에 남은 사용량을 알 수 없으니, 각 도구의 알림과 공식 안내를 확인하세요.
