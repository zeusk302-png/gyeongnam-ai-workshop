# 무료 계정 한도와 실습 사용법

공식 안내 확인일: 2026-09-27

개인 무료 계정 기준으로 설명합니다. 학교·직장 계정은 기관의 라이선스나 관리자 설정에 따라 이용 범위가 다를 수 있습니다.

수업 전에 남은 사용량을 확인하세요. 긴 문서나 긴 대화는 사용량을 더 많이 쓸 수 있습니다. 제한 알림이 뜨면 다시 사용할 수 있는 시간을 확인하세요.

## 수업 전 준비

1. 각 도구에 본인 계정으로 로그인하세요. 유료 결제나 무료 체험은 신청하지 않아도 됩니다.
2. 설정의 사용량 메뉴나 제한 알림을 확인하세요. 수업 전에 이미 사용한 계정은 도중에 한도에 걸릴 수 있습니다.
3. 처음 쓰는 도구라면 입문용을 고르세요. 긴 업무 문서로 연습하려면 확장본을 고르세요.
4. 제공된 질문을 한 번 보내고 답변을 끝까지 읽으세요. 고칠 부분이 있을 때만 추가로 요청하세요.
5. 한도에 걸리면 받은 답변을 저장하세요. 아래 안내에 따라 원문과 비교하거나 짝과 진행하면 됩니다. 새 대화나 새 노트북을 열어도 사용량 한도가 초기화되지는 않습니다.

## 수업에서 보낼 질문 수

여기에 적힌 질문 횟수는 수업에서 보낼 횟수입니다. 남은 사용량에 따라 도중에 제한될 수 있습니다. 답변과 원문을 비교하거나 직접 계산하는 활동은 계속 진행하세요.

질문 수를 줄이면 Gemini 4회·NotebookLM 채팅 3회·Claude 4회, 총 11회로 진행할 수 있습니다. 계정에 남은 사용량에 따라 도중에 제한될 수 있습니다. 마지막 업무 계획은 기록지에 직접 쓰고, 오디오는 시간이 남으면 만들어 보세요.

## Gemini

무료는 표준 사용량 한도. 고정 질문 횟수는 현재 공식 안내에 공개되지 않았습니다.

컴퓨팅 기반 한도 · 5시간마다 갱신 · 주간 한도 적용

### 사용량은 어디서 확인하나요?

웹 왼쪽 아래 설정 → 사용량 한도(Usage Limits). 메뉴가 다르면 한도 도달 알림의 다음 갱신 시각을 확인합니다.

### 공식 안내에 나온 한도

- 2026-05-17 변경 안내 기준입니다. 질문 복잡성·모델·기능·누적 대화 길이가 사용량에 영향을 줍니다.
- 무료 문맥 용량은 공식 표상 32k 토큰입니다. 문자 수나 무료 질문 횟수와 같은 단위가 아닙니다. 이번 수업에서는 여러 원자료를 한꺼번에 넣지 않습니다.

### 무료 계정으로 실습하기

1. 무료로 선택할 수 있는 기본 모델로 시작하세요. 모델을 고를 수 있다면 짧은 답장·요약에는 Flash-Lite 계열과 기본 사고 수준을 선택하세요. 계정에 따라 모델 이름은 다를 수 있습니다.
2. 학생 문의 단계의 첫 질문을 전체 복사해 보내세요. 답장을 원문 P1–P5와 비교한 뒤 필요한 부분만 한 번 더 수정해 달라고 하세요.
3. 회의와 예산 실습은 각각 새 대화를 열고 해당 자료만 넣으세요. Google Drive나 메일을 연결할 필요는 없습니다.
4. 결정된 일과 미정인 일, 담당자와 마감일을 원문과 비교하세요. 예산 합계도 직접 계산하세요. 이번 실습에서는 Deep Research나 이미지·동영상 생성은 사용하지 않습니다.

### 질문 수를 줄여 진행하려면

답장 작성·수정, 회의 정리, 예산 검산에 총 5회 질문합니다. 한도가 부족하면 4회로 줄이고 나머지는 직접 확인합니다.

- 학생 문의 첫 질문과 수정 질문 1회, 회의 첫 질문 1회, 예산 첫 질문 1회만 전송합니다(총 4회 계획).
- 회의의 ‘정해진 일과 미정인 일 다시 확인하기’ 질문은 생략하고 녹화본 미정·업무 3개·담당과 마감일을 원문과 직접 대조합니다. 예산은 응답을 받은 뒤 6행을 직접 검산합니다.
- 확장본 회의 실습에서 요약이 나오지 않았을 때만 다시 요청하세요.

### 한도에 도달하면

한도 알림에서 다시 쓸 수 있는 시간을 확인하세요. 이미 받은 답변이나 실습 예시 화면을 원문과 비교하고, 예산은 계산기로 다시 계산하세요. 모델을 바꿔 계속 쓸 수 있는지는 계정에 표시된 안내를 확인하세요.

## NotebookLM · Gemini Notebook

무료는 표준 사용량 한도. 채팅·오디오의 고정 무료 횟수를 새 정책에서 공개하지 않습니다.

2026-09-02부터 컴퓨팅 기반 · 5시간 갱신 · 주간 한도 적용

### 사용량은 어디서 확인하나요?

웹 오른쪽 위 설정 → 사용량(Usage). 채팅 아래의 잔여 사용량·갱신 시각과 Studio 생성의 예상 사용량도 확인합니다.

### 공식 안내에 나온 한도

- 현재 공식 저장 개수 표: 사용자당 노트북 100개, 무료 노트북당 소스 50개. 하루 생성 가능 횟수와는 다른 한도이며 변경될 수 있습니다.
- 소스 안내: 소스당 50만 단어(영문 기준), 로컬 업로드 파일당 최대 200MB. 이번 수업은 노트북 1개와 작은 TXT 소스 2개만 사용합니다.

공식 안내 두 곳의 내용이 다릅니다. 요금제 표에는 ‘채팅 50회/일·오디오 3회/일’이 남아 있지만, 9월 2일 변경 안내는 계산량 기준으로 설명합니다. 이 수업에서는 새 안내를 따르며, 실제 사용 가능 여부는 계정 화면에서 확인하세요.

### 무료 계정으로 실습하기

1. 새 노트북을 만들고 소스 추가를 누릅니다. 입문용 04A·04B 또는 확장본 14A·14B 중 한 쌍만 업로드하거나 각각 별도 텍스트 소스로 붙여 넣습니다.
2. 두 자료가 소스 목록에 나타나고 선택됐는지 확인합니다. 사용 안내·질문 모음·검토 기준 파일은 소스로 넣지 않습니다.
3. 핵심 요약을 질문한 뒤 참가자 안내와 신청 마감 등을 묻습니다. 답변의 인용을 눌러 A3·B4 원문과 전후 문장을 직접 읽습니다.
4. 주차 요금처럼 없는 정보와 녹화본처럼 미정인 정보를 구분합니다. 마감일만 보고 업무 완료를 추정하지 않습니다.
5. 오디오는 텍스트 검토를 마치고 사용량이 남을 때만 Studio에서 한국어로 한 번 생성합니다. 대기하거나 제한되면 텍스트 요약 대조로 마칩니다.

### 질문 수를 줄여 진행하려면

노트북 1개·소스 2개·채팅 5회 계획. 사용량이 적으면 채팅 3회와 원문 대조로 진행합니다. 오디오 생성은 여유가 있을 때 선택 1회입니다.

- 핵심 요약, 참가자 안내 FAQ, 자료에 없는 정보 확인의 첫 질문만 보냅니다(채팅 3회 계획).
- 녹화본 재질문 대신 FAQ와 B4 원문을 비교합니다. 완료 여부 재질문 대신 B 문서 머리말의 기준일과 B2의 마감일·완료 기록 유무를 직접 비교합니다. A3의 신청 마감 인용도 직접 엽니다.
- 소스 업로드와 인용 열기는 이 채팅 전송 횟수 계산에서 제외했습니다. 사용량 소비가 전혀 없다는 뜻은 아닙니다. 오디오는 생략합니다.

### 한도에 도달하면

A·B 파일을 나란히 열어 답변과 같은 내용이 있는 문단을 찾아보세요. 질문이나 오디오 생성 버튼을 반복해서 누르지 마세요. 옆 사람이 사용할 수 있다면 함께 진행하고, 각자 확인한 내용을 기록하세요.

## Claude Free

고정 메시지 횟수는 공개하지 않습니다. 수요와 질문·첨부·대화 길이에 따라 달라집니다.

5시간 세션 한도 · 실제 화면의 재개 가능 시각 확인

### 사용량은 어디서 확인하나요?

사용량 메뉴가 보이지 않으면 대화에 뜨는 한도 알림에서 다시 쓸 수 있는 시간을 확인하세요.

### 공식 안내에 나온 한도

- 짧은 질문과 긴 문서 요청은 같은 양을 소비하지 않습니다. 긴 첨부·누적 대화·선택 모델·도구 사용이 영향을 줍니다.
- 사용량이 초기화되면 이전 대화를 이어서 사용할 수 있습니다. 새 대화를 열어도 계정의 사용량 한도가 초기화되지는 않습니다.

### 무료 계정으로 실습하기

1. 무료로 가능한 일반 채팅에서 시작합니다. 업그레이드·결제 없이 제공된 05 또는 확장 15의 자료가 포함된 목차 질문을 넣습니다.
2. 초안·문체·분량 수정은 같은 대화에서 이어갑니다. 첫 질문에 넣은 원자료를 수정할 때마다 다시 붙여 넣지 않습니다.
3. 답변과 비교 표를 메모나 문서에 복사해 저장하세요. DOCX·PPTX 파일을 자동으로 만들 필요는 없습니다.
4. 참여 인원·이수율·증감률·퍼센트포인트를 직접 계산하세요. 만족도 응답 수가 맞는지, 자료에 없는 내용을 단정하지 않았는지도 확인하세요. AI가 “검증 완료”라고 해도 이 과정은 직접 진행하세요.
5. 확장본이 어렵다면 입문용으로 바꾸고 새 대화에서 시작하세요. 원자료를 임의로 잘라 넣으면 필요한 조건을 놓칠 수 있습니다. 자료를 바꾸어도 사용량 한도는 그대로입니다.

### 질문 수를 줄여 진행하려면

목차 작성부터 최종 확인까지 기본 6회 질문합니다. 잘못된 단정이 남으면 1회 더 수정합니다. 한도가 부족하면 4회만 질문하고 나머지는 직접 확인합니다.

- 목차·초안·문체 수정·분량 수정의 첫 질문만 전송합니다(총 4회 계획).
- 초안의 표를 직접 검산하세요. 마지막 확인 질문과 사실을 고치는 질문은 추가로 보내지 않고, 검토 기준 파일을 보면서 직접 수정하세요.
- 최종 보고서와 바꾼 표현, 계산 결과를 기록합니다. 모델의 자체 글자 수 추정은 직접 센 값과 구분합니다.

### 한도에 도달하면

마지막으로 받은 초안을 메모나 문서에 복사하세요. 원자료와 비교하면서 문체·분량·수치를 직접 고치면 됩니다. 초안을 받기 전에 막혔다면 09 보고서 예시나 짝의 답변을 보고 수정하세요.

## 결과 기록

직접 실행했는지, 짝과 함께 했는지, 강사 화면이나 예시 화면을 보고 확인했는지 적으세요. 답변에서 고친 문장과 직접 계산한 숫자도 남겨 두세요. 한도에 걸리면 이미 받은 답변이나 예시 화면을 원문과 비교하며 계속 진행할 수 있습니다.

한도와 메뉴는 확인일 이후 바뀔 수 있습니다. 예시 화면만으로는 내 계정에 남은 사용량을 알 수 없으니, 각 도구의 알림과 공식 안내를 확인하세요.
