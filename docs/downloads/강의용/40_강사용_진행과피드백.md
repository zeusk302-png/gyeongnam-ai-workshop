# 강사용 진행과 피드백
v1.7.0 · 2026-09-28 · 업무실습 보완 해설

이 문서는 3시간 시간표에 설명 시간을 추가하는 자료가 아닙니다. 기존 실습 안의 대기·읽기·검토 시간을 구체적인 참가자 활동으로 나누었습니다. 기본 질문 횟수는 Gemini 3회와 선택 수정 1회, NotebookLM 3회, Claude 4회입니다. 마지막 검산과 짝 검토, 이 문서의 각 단계 끝에 있는 짧은 선택 과제 11개는 추가 AI 질문 없이 직접 수행합니다. 별도로 제공하는 추가 실습 8개는 다른 원자료와 질문을 사용하는 수업 후 연습이며, 실행하면 해당 실습의 질문량이 추가됩니다.

## 사용 방법

- 웹 연결 원본은 `제작자료/lesson-enrichment.json`입니다. 아래 각 절의 step ID와 `PPT_NOTE` 표시는 웹 실습·PPT 발표자 노트를 같은 활동에 연결하기 위한 편집용 표식입니다.
- 11개 주요 활동은 총 118분입니다. 준비 20분, NotebookLM 생성·소스 추가 13분, 인계 설명 4분, 마무리 15분을 더하면 학습 170분이며 휴식 10분을 포함해 전체 180분입니다.
- 아래 ‘교사가 작성한 검토 예시’는 수업용으로 만든 잘못된 문장과 수정안입니다. 실제 서비스 응답이나 실측 결과라고 소개하지 않습니다. 일부 발췌 예시는 과제의 전체 글자 수 조건을 대신하지 않습니다.
- 예시를 처음부터 정답으로 읽어 주지 않습니다. 잘못된 문장만 먼저 보여 주고 20~30초 표시하게 한 뒤 수정안을 공개합니다. 두 단계는 해당 실습 시간 안에 포함합니다.
- 짝 검토는 한 사람이 작성한 답을 다른 사람이 대신 완성하는 시간이 아닙니다. 확인할 원문과 잘못된 문장을 서로 가리키고, 각자 자신의 결과를 고쳐 저장하게 합니다.
- 답변 생성이 길어지면 대기 중 원문 표시·직접 계산을 먼저 진행합니다. 정해진 시간 안에 답변이 오지 않으면 확보한 실제 실행 화면이나 여기의 교사 작성 예시로 검토를 이어가고, 직접 실행·화면 비교·예시 검토 중 실제 수행한 방법을 기록하게 합니다.
- 이 문서의 11개 짧은 선택 과제는 기존 결과를 직접 고치는 수업 후 활동입니다. 수업 중에는 필수 활동을 끝낸 참가자만 남은 시간에 시작하며, 180분을 늘리거나 AI 질문을 추가하지 않습니다. 별도 추가 실습 8개의 시간과 AI 질문은 본 수업 180분·10~11회 계획에 포함하지 않습니다.
- 새 연습 자료 묶음은 기본 업무실습과 답안·날짜가 다를 수 있습니다. 고른 자료와 질문을 한 묶음으로 쓰고 원래 실습의 정답을 옮겨 적용하지 않습니다.

## 공통 평가 방법

각 활동의 짝 검토 질문을 모두 확인하면 해당 활동의 산출물을 저장합니다. 답변의 문장과 문서 순서가 정답 예시와 같을 필요는 없습니다. 필요한 행·문서가 있고, 핵심 사실과 상태가 맞으며, 원문에서 확인한 내용과 제안이 구별되는지를 봅니다.

피드백은 ‘틀렸습니다’로 끝내지 않고 **문장 지목 → 원문 위치 확인 → 고칠 동사·수치 말하기 → 참가자가 직접 수정** 순서로 합니다. 아래 ‘우선 고칠 오류’가 남으면 표현 다듬기보다 먼저 고칩니다. 시간이 부족하면 미완료 상태와 남은 항목을 기록하고 다음 시간표로 이동합니다. 질문을 더 보내서 시간을 연장하지 않습니다.

활동별 확인 기록은 다음 네 칸이면 충분합니다.

| 원문에서 확인한 항목 | 처음 결과의 문제 | 직접 고친 내용 | 아직 확인하지 못한 내용 |
|---|---|---|---|
| 문단·행 ID·발언 시각 | 단정·누락·계산·상태 중 구체 내용 | 바뀐 수치·동사·조건 | 담당자에게 물을 질문 또는 미완료 |
