# 선택·복습용 추가 실습 과제지

자료 버전 1.7.0. 모든 사건·기관 문서·수치·승인은 교육용 가상 자료입니다. 이 파일과 동봉 해설은 실제 AI 실행 결과나 화면 캡처가 아닙니다.

8개 과제는 기존 180분 본수업 밖의 선택 과제입니다. 180분 본수업을 마친 뒤 수업 후 복습으로 필요한 과제를 골라 배정합니다. 권장 시간은 읽기·AI 요청·사람의 검토·저장을 포함한 활동 시간이며 모델이 보장하는 응답 시간이 아닙니다. 시간은 질문 수나 무료 제공량을 뜻하지 않습니다. 권장 추가 전송 계획은 p01~p07 과제당 1회, p08은 도구별 1회로 총 3회입니다. 8개를 모두 하면 최소 계획 10회가 본수업 요청량에 추가됩니다. 이는 무료 제공 횟수가 아니며 파일 분할 전송·재요청·수정 질문을 보내면 사용량이 더 들 수 있습니다.

처음에는 90번 해설을 열거나 AI 소스로 넣지 않습니다. 원문만으로 결과를 저장한 뒤 해설과 비교합니다. 수치 검산은 AI에게 재질문한 답만 믿지 말고 계산기 또는 표 계산으로 직접 합니다. 연결 서비스에 실제 메일을 보내거나 가상 승인을 실무에 적용하지 않습니다.

추가 실습은 본수업의 대화·노트북을 보존하고 별도 대화 또는 별도 노트북에서 시작합니다. 본수업 질문으로 돌아갔을 때 후속 승인·보완 수치가 섞이지 않도록 하기 위한 자료 구분입니다.
