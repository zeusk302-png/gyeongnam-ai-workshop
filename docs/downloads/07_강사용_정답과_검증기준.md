# 강사용 정답과 검증 기준

**모든 예시는 가상 교육 데이터입니다.** 아래 답안과 표현이 정확히 같을 필요는 없습니다. 사실, 계산, 구분이 맞는지를 확인하세요. 이 파일은 NotebookLM 소스로 업로드하지 않습니다.

## 1. 학생 문의 답장

필수 사실은 수강정정 기간 `2026-10-06 09:00~2026-10-12 18:00`, 학생의 직접 신청, 여석이 없을 때 상담창구 문의, 이메일로 신분증 사진을 요구하지 않음입니다. 여석 수·예외 승인·처리 기간·실제 URL을 만들어 넣으면 수정이 필요합니다.

답장 예시:

> 제목: [답변] 수강정정 기간 및 분반 변경 안내  
> 안녕하세요. 수강정정은 2026년 10월 6일 09:00부터 10월 12일 18:00까지 가능합니다.  
> 해당 기간에 가상 학사 포털의 ‘수강신청 > 수강정정’에서 02분반의 여석과 변경 가능 여부를 확인한 뒤 직접 신청해 주세요.  
> 여석이 없다면 소속 학과의 가상 상담창구에 문의해 주시기 바라며, 현재 자료로는 예외 승인 여부와 처리 기간을 안내드리기 어렵습니다.  
> 이 문의에 대해 학번이나 신분증 사진을 이메일로 보내실 필요는 없으며, 필요한 정보와 공식 제출 방법은 상담창구에서 안내받으시면 됩니다.

발송 전 확인: 기간과 메뉴가 현재 기관 기준과 일치하는지, 상담창구 안내가 정확한지. 실제 기관에 보내는 답장으로 사용하지 않도록 가상 표시를 유지합니다.

## 2. 회의 정리

결정 사항은 교육 일시·장소, 정원 30명, 참가비 무료, 노트북·충전기 지참, 가상 자료만 사용, 수정 예산 845,000원입니다. 원문 사실을 묶어 정리해도 됩니다.

**미정:** 종료 후 녹화본 제공 여부. 검토가 필요하다는 사실만 기록되어 있으므로 제공이나 미제공으로 확정하면 안 됩니다.

| 할 일 | 담당 역할 | 마감일 |
|---|---|---|
| 참가 안내문 정리 | 운영담당 | 2026-10-19 |
| 가상 실습 자료 완성 | 교육담당 | 2026-10-21 |
| 장비대여 비용을 50,000원으로 수정한 예산표 공유 | 행정담당 | 2026-10-23 |

위 업무는 **3개**입니다. 완료 기록이 없으므로 완료로 표시하지 않습니다.

주차 요금이 0원이라고 답하거나 무료 참가비를 무료 주차로 확대하면 오답입니다. 녹화본을 제공하지 않는다고 단정해도 오답입니다. 예정된 마감일을 근거로 업무가 완료됐다고 추정하면 안 됩니다.

핵심 3가지 요약 예시: ① 교직원 행정 업무 초안 작성과 검증을 연습한다(A1). ② 노트북·충전기와 로그인 점검을 준비한다(A4). ③ 가상 자료만 사용하고 수치·출처를 대조하며 녹화본은 미정으로 안내한다(A5, B4).

인용 표시는 실제 도구의 소스 인용을 열어 원문을 확인합니다. AI가 본문에 직접 적은 `[A4]` 문자열만으로 검증 완료로 간주하지 않습니다.

## 5. Claude 보고서 수치 정답

| 지표 | 이전 | 이번 | 차이/증감률 계산 | 보고용 결과 |
|---|---:|---:|---|---|
| 신청 인원 | 24명 | 30명 | 30−24=6, 6÷24×100=25 | 6명 증가, 25.0% 증가 |
| 실제 참여 인원 | 20명 | 28명 | 28−20=8, 8÷20×100=40 | 8명 증가, 40.0% 증가 |
| 이수 인원 | 16명 | 24명 | 24−16=8, 8÷16×100=50 | 8명 증가, 50.0% 증가 |
| 이수율 | 16÷20×100=80% | 24÷28×100=85.714285…% | 85.714285…−80=5.714285… | 80.0%→85.7%, **5.7%p 상승** |
| 집행액 | 720,000원 | 845,000원 | 125,000÷720,000×100=17.361111… | 125,000원 증가, 17.4% 증가 |
| 참여자 1인당 집행액 | 720,000÷20=36,000원 | 845,000÷28=30,178.571428…원 | 이번−이전=−5,821.428571…원 | 36,000원→30,179원, 5,821원 감소 |
| 만족도 평균 | 4.2점 | 4.5점 | 4.5−4.2=0.3 | 응답자 평균 0.3점 상승 |

추가 질문의 정답: 참여자 1인당 집행액 감소율은 `(36,000−845,000÷28)÷36,000×100=16.170634…%`, 보고용으로 **16.2% 감소**입니다. 반올림된 30,179원을 다음 계산의 입력값으로 쓰지 않습니다.

오류 예시와 수정:

- “이수율이 5.7% 증가” → 이수율 차이는 **5.7%p 상승**. 이수율 자체의 상대 증가율을 굳이 구하면 약 7.1%지만 이 보고서에는 %p를 사용합니다.
- “참여자 30명 중 24명이 이수, 이수율 80%” → 30명은 신청 인원입니다. 실제 참여 인원 28명을 분모로 하여 85.7%입니다.
- “AI 도구 덕분에 만족도가 높아짐” → 인과관계를 확인한 자료가 없습니다. 응답자 평균 변화만 기술합니다.
- “로그인 실패로 4명 미이수” → 미이수 사유를 수집하지 않았습니다. 로그인 지연과 미이수의 관계를 단정하지 않습니다.
- “사전 로그인 점검을 시행했다” → 다음 회차의 개선 제안입니다. 이번에 실행한 일처럼 쓰지 않습니다.

보고서 예시:

> **교직원 AI 업무 활용 워크숍 결과 보고 — 가상 실습**  
> • 실제 참여 인원은 20명에서 28명으로 8명(40.0%) 증가함.  
> • 이수율은 80.0%에서 85.7%로 5.7%p 상승함.  
> • 집행액은 720,000원에서 845,000원으로 125,000원(17.4%) 증가함.  
> 이번 회차는 이메일, 회의 정리, 예산 검산, 자료 근거 확인, 결과 보고서 작성 실습으로 운영함. 이수 인원은 24명이며, 참여자 1인당 집행액은 30,179원으로 이전 회차의 36,000원보다 낮아짐. 시작 시 일부 참가자의 로그인 지연으로 2인 1조 활동을 병행함. 만족도는 응답자 평균 기준 4.2점에서 4.5점으로 높아졌으나 변화 원인과 미이수 사유는 확인할 수 없음. 다음 회차에는 사전 로그인 점검 안내와 보충 실습 제공을 검토할 것을 제안함.

위 예시는 핵심 사실의 예시이며 700~900자 길이 조건의 모범답안은 아닙니다. 참가자의 결과물에는 비교 표도 포함하도록 안내합니다.

## 6. 현장 확인 기준

각 결과물은 다음 조건을 모두 충족하면 완료로 봅니다.

| 결과물 | 확인 기준 |
|---|---|
| 이메일 | 정정 기간 정확, 다음 행동 제시, 예외 승인이나 개인정보 회신을 요구하지 않음 |
| 회의 정리표 | 결정·미정 구분, 업무 3개와 담당·마감일 일치 |
| 예산 검산 | 오류 행 1개 발견, 두 합계 구분, 수정 합계 845,000원 확인 |
| 자료 요약 | 최소 2개 인용을 열어 원문 확인, 주차 요금에 근거 없음 표시 |
| 보고서 | 참여 28명, 이수율 85.7%, +5.7%p, 집행 845,000원, 확인 안 된 원인 단정 없음 |

성공 기준은 도구가 한 번에 정답을 내는 것이 아니라 참가자가 원문과 계산으로 오류를 찾아 고치는 것입니다.


## 7. 실제 실행한 최종 보고서 참고

`09_Claude_최종보고서_검토예시.txt`는 실제 Claude 최종 응답에서 보고서 본문과 표를 보존한 파일입니다. 본문은 공백 포함·줄바꿈 제외 **587자**입니다. 행사정보·소제목은 포함하고 제목·비교표·표주석·검토메모는 제외했습니다. 화면의 “약 615자”는 모델의 자체 추정으로, 실측값과 다릅니다.

“원자료 미제공”은 “원자료가 없음”과 다르고, “개선 제안”은 “미시행 확정”과 다릅니다. 원자료로 확인할 수 없는 시행 여부는 확인 필요로 남깁니다.
