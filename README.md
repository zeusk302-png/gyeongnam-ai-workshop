# 교직원 AI 업무 실습

Gemini, NotebookLM, Claude로 쌓인 문의와 흩어진 업무 자료를 정리하는 3시간 실습입니다. **v1.9는 강의용 PPT의 디자인과 참여 활동을 새로 구성했습니다.** 수업은 업무실습으로 시작하며, 조작을 먼저 익히고 싶을 때 짧은 **기본연습**을 선택할 수 있습니다.

**[강의 바로가기](https://zeusk302-png.github.io/gyeongnam-ai-workshop/)**

| 도구 | 받은 자료 | 만들어 볼 문서 |
|---|---|---|
| Gemini | 문의 30건·메일 60개·운영기준·승인·접수대장, 회의 기록, 구매 요청 24행 | 문의 30행·답장 5개 초안과 담당별 확인·공지 수정안, 회의 인계표, 구매 검토표 |
| NotebookLM | 최초 공지·담당자 인계·변경 승인·문의 목록의 소스 4개, 참가 문의 14건 | 최신 참가 안내, 공지 수정 목록, 문의 처리표 |
| Claude | 출석 대장 30행, 설문 응답 25행, 지출·현장 기록·부서 메일 | 전체 보고서, 계산표, 후속 업무표, 부서장 전달 메일 |

대표 문의 실습은 원문 네 개를 합친 파일을 첨부하고 짧은 질문을 보내는 방식입니다. 같은 Q01·Q04·Q12 세 건을 직접 읽고 AI 초안과 대조하며, 나머지 미검토 범위를 따로 남깁니다. 직접 3건과 AI 30건의 시간으로 절감률을 계산하지 않습니다. 준비·대기·검토·수정·저장 시간을 모두 포함해 AI 사용 여부를 판단합니다.

2026-09-28 실행 시험에서는 세 건의 접수 상태 조회는 맞았지만 30행 전체 생성은 중단됐습니다. 생성 구간 안에 실패하면 교사 예시와 원문을 비교하도록 대체 진행을 넣었습니다. 교사 예시를 AI가 생성한 결과로 표시하지 않습니다.

본문은 **업무 확인 → 실습하기 → 결과 검토**로 나눴습니다. PC 본문 18px, 휴대폰 본문 17px을 기준으로 읽기 폭·행간·대비를 조정하고, 긴 원문은 별도 읽기 창에서 확인할 수 있습니다. 기존 기본연습·추가 실습은 유지합니다.

- **[수업용 PPT 58장](https://zeusk302-png.github.io/gyeongnam-ai-workshop/#slides)**: 큰 문장과 숫자, 확대된 실제 화면을 중심으로 구성했습니다. 먼저 답을 고르고 다음 장에서 자료를 확인하는 활동을 포함합니다. 본 수업 50장과 선택 실습 8장이며, 편집 가능한 텍스트·표와 발표자 노트·실습 바로가기를 제공합니다. PDF는 읽기용입니다.
- **[추가 실습 8개](https://zeusk302-png.github.io/gyeongnam-ai-workshop/#practice-bank)**: 새 문서를 받아 기존 답장·인계표·구매표·안내문·보고서를 다시 작성합니다. 모두 진행하면 약 145분이며 본 수업 밖의 선택·복습 활동입니다.
- **11개 실습의 진행 보강**: 작성 시간, 검토 전·후 예시, 짝 검토 질문과 수정본 저장까지 연결했습니다. 강사용 진행안과 참가자 결과 작성 양식도 제공합니다.

수업은 **설명·실습 170분과 휴식 10분, 총 180분**입니다. 같은 활동에서 두 버전의 자료를 모두 진행하지 않습니다. 원자료와 답이 다르므로 버전을 바꾸면 새 대화나 새 노트북에서 시작하세요. 각 단계에는 복사할 질문, 직접 확인할 항목, 실습 화면과 도구 바로가기가 있습니다. 강사 소개와 무료 계정 사용 안내도 제공합니다.

실습 자료는 교육용 가상 자료입니다. 무료 이용 한도는 계정과 시점에 따라 달라질 수 있으므로 강의의 무료 계정 안내를 확인하세요.

## 사이트 구성

`docs/`에 게시할 HTML·CSS·JavaScript, 자료와 이미지를 보관합니다. GitHub Pages는 `main` 브랜치의 `/docs` 폴더를 게시합니다. 설치나 별도 빌드 없이 정적 파일로 실행됩니다.

로컬에서 확인하려면 저장소 루트에서 다음 명령을 실행하고 `http://127.0.0.1:8765/docs/`를 여세요.

```sh
python -m http.server 8765 --bind 127.0.0.1
```

검토 기록과 완료 표시는 사용 중인 브라우저에 저장됩니다. 기본연습과 업무실습 기록은 구분되며, 준비·마무리 기록은 함께 사용합니다. 이전 확장본 기록도 `전체 기록 받기`로 내려받을 수 있습니다. 다른 기기와 자동으로 동기화되지 않습니다.

업무실습 원자료와 180분 시간표는 v1.8의 구성을 유지합니다. v1.9 PPT·PDF는 `제작자료/pptx-v1.9/slides-manifest.json`에서 `python 제작자료/publish_slides_v19.py`로 연결합니다. 기존 생성기를 마지막에 실행하면 최신 슬라이드 연결을 덮어쓸 수 있으므로 주의하세요.

글꼴과 아이콘의 라이선스는 `docs/assets/fonts/`와 `docs/assets/icons/`에 있습니다.
